# codex-barbar 1.0.0

codex-barbar is a Windows 11 x64 tray application that shows your Codex
usage and limits at a glance. This is the first stable V1 release.

## What's included

- Tray panel with Codex quota windows (5-hour and weekly), reset times, and
  per-profile switching.
- Settings: general, providers, notifications, menu bar, menu, usage/spend,
  advanced, and about tabs.
- Current CLI profile is read-only; managed profiles use isolated
  `CODEX_HOME` runtimes and Windows DPAPI (Current User) credential
  protection.
- Redacted rotating logs (5 MiB / 14 days) and redacted diagnostic export.
- Manual-only update check; the app never downloads or applies updates
  without your action.
- Per-user NSIS installer (no elevation) and a portable ZIP; both store
  data under `%LOCALAPPDATA%\codex-barbar`.

## Downloads

```text
codex-barbar_1.0.0_x64-setup.exe      NSIS per-user installer
codex-barbar_1.0.0_x64-portable.zip   Portable build
SHA256SUMS.txt                        SHA-256 for both artifacts
codex-barbar_1.0.0_sbom.spdx.json     SPDX 2.3 software bill of materials
```

Binaries are unsigned when no Authenticode certificate is supplied;
SmartScreen may warn. Verify hashes with `SHA256SUMS.txt` before running.

## Requirements

- Windows 11 23H2 or newer, x64
- A working Codex installation signed in with `codex login`

## Tested versions

- Codex CLI 0.146.0 (App Server protocol is experimental)
- Windows 11 23H2 x64

## Known limitations

- Codex only. No other provider, browser-cookie import, API-key account, or
  usage notification surface is included in V1.
- The Codex App Server protocol is experimental; protocol changes may
  require an update.
- No automatic updates. Use the manual check in Settings.
- Winget, MSIX, Microsoft Store, and automatic updater work remain outside
  V1.

## Privacy

No telemetry. All data stays local under `%LOCALAPPDATA%\codex-barbar`; see
[PRIVACY.md](../../PRIVACY.md) for the full threat boundary.
