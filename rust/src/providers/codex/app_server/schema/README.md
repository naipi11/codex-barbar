# Codex App Server schema captures

This directory stores JSON schemas generated by a real, locally installed
`codex` CLI so the client wire models in `rust/src/providers/codex/app_server/`
can be checked against tested versions.

## Capture process

Run from the repository root:

```powershell
.\scripts\codex-app-server-smoke.ps1
```

The script resolves Codex through the same fail-closed resolver the product
uses, invokes the trusted command directly with the fixed
`app-server generate-json-schema --out <temp>` arguments, copies the generated
schemas under a version slug directory, and records a `manifest.json` with the
exact probed version and SHA-256 hashes.

## Contents

- `<version-slug>/` – generated schema files for one tested Codex version.
  The slug replaces every character outside `[A-Za-z0-9._-]` with `_`.
- `<version-slug>/manifest.json` – `codexVersion` (exact probed output),
  `capturedAtUtc`, and `files` with relative paths and SHA-256 hashes.
- `README.md` – this file.

## Rules

- Never commit credentials, account identity, quota values, tokens, raw RPC
  output, or absolute user paths under this directory.
- Only record a version as compatible when `docs/compatibility/codex-app-server.md`
  contains local Windows evidence for that exact version and installation form.
- CI runs the deterministic PowerShell fake-server contract suite, not a
  real signed-in smoke. Real smoke remains a local-only operation.
